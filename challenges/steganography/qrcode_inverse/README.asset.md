# Asset manquant

L'export Notion ne contient pas l'image du QR code coloré pour ce défi.

Avant déploiement sur CTFd :

1. Ajouter l'image du QR code (couleurs, noir/blanc inversé intentionnellement).
2. Mettre à jour `challenge.yml` : section `files:` avec le nom du fichier.
3. Remplacer le placeholder dans `private/flag.txt` et exécuter `./encrypt.sh`.

Voir aussi la section **Missing assets** du README à la racine du dépôt.
